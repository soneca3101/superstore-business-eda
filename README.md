# Superstore Sales — Business-Driven Exploratory Data Analysis

## Project Overview

This project presents a business-driven Exploratory Data Analysis using the
Superstore Sales dataset. The goal is to identify the main drivers of sales and
profitability and translate analytical findings into business recommendations.

Unlike a purely technical EDA, this project focuses on answering business questions
related to discount strategy, profitability, regional performance, product categories,
customer segments, and shipping efficiency.

## Business Problem

The Superstore wants to understand why some areas of the business generate strong
sales but weak or negative profit. The analysis investigates whether discounts,
product mix, region, segment, or shipping behavior are affecting profitability.

## Dataset

The dataset contains transactional sales records, including:

- Order information
- Customer segment
- Product category and sub-category
- Sales
- Profit
- Discount
- Region
- Shipping mode
- Order and shipping dates

Source: Kaggle Superstore Dataset
